# This file no longer holds a ratchet number. It used to, and that was the
# defect: a committed number is a snapshot of one tree, so every other tree
# disagrees with it, and the standing instruction it produced — "regenerate the
# baseline on every merge" — teaches people to regenerate without looking, which
# is the exact reflex a ratchet exists to prevent. It went stale twice in one
# day, and the same design red-lined `main` for 8 commits via #8073.
#
# The gate now compares against the MERGE-BASE, which asks the only question it
# cares about: does THIS change add portable shell? Whatever `main` did
# meanwhile is not this change's doing. Nothing here needs updating, ever.
#
# `origin_portable` is the portable figure immediately before epic #7810's first
# port commit (143fe332^, PR #7953). It is the denominator progress is measured
# against and must NEVER be regenerated — an origin that moves measures nothing.
origin_portable 38374

# `origin_rev` is that same fixed point as a revision, so tooling can scan the
# epic's whole history rather than re-deriving it from the comment above. It
# pairs with `origin_portable` and is equally immovable. Used by the report to
# total the floor growth that has been deliberately declared and accepted
# (`Shell-Budget-Growth:` trailers, #8154) since the epic began.
